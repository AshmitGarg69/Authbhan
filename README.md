# AuthBahn

> Official CRISPR-IIITN Chrome extension for automating Fortinet captive portal login.  
> *"Forever forget the pain of logging into the campus network again."*

---

## 📖 About AuthBahn

This is a Chrome extension you can use to forever forget the pain of logging into the campus network again. This is one of many in-house solutions made by **CRISPR** (IIIT Nagpur).

Having been in private use since at least April 15, 2024, it has been opened to the community.

### 🇩🇪 Origin Lore
> The name **AuthBahn** is derived from *AutoBahn*, the legendary highways with no speed limit in Germany. Fast. Unrestricted.

---

- `AuthBahn/` - Extension files (Windows / unpacked directory)

---

## 🛠️ Installation

To install this extension:

1. Turn on **Developer Mode** in your browser (`chrome://extensions`).
2. Download or clone this repository.
3. Click **"Load unpacked"** and select the `AuthBahn` directory.
4. If you have any doubts, a quick search for *"How to load an unpacked extension in Chrome"* will guide you.

---

## 🚀 How to Use

1. Click on the extension icon and select **"Add Fortigate ID"**.
2. Save your LDAP credentials (username and password).
3. Connect to the campus network — AuthBahn will automatically populate and submit credentials on the Fortinet login page (`192.168.55.253`).
4. To log out, use the **Logout** button in the extension popup.

---

## 🔒 Zero Telemetry

> Data is **not** sent to CRISPR's servers. Your credentials are strictly stored locally within your own browser storage. That's about it.
